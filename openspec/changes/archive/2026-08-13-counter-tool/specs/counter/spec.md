## ADDED Requirements

### Requirement: 计数器的创建、编辑与删除
系统 SHALL 提供计数器的增删改能力，计数器持久化到本地 JSON 文件，重启后仍存在；计数器由名字、重置周期与可选目标值构成。

#### Scenario: 创建计数器后出现在 dashboard
- **WHEN** 用户在计数器详情页填写名字、选择周期并保存
- **THEN** 新计数器持久化，dashboard 上立即出现对应卡片

#### Scenario: 编辑计数器
- **WHEN** 用户修改计数器的名字、周期或目标值并保存
- **THEN** 计数器持久化更新，已累计的次数桶保留，dashboard 卡片与详情页列表同步反映新配置

#### Scenario: 删除计数器需确认
- **WHEN** 用户在详情页删除一个计数器
- **THEN** 系统先弹出确认提示，确认后计数器删除，dashboard 对应卡片消失

#### Scenario: 重启后计数器仍在
- **WHEN** 应用重启
- **THEN** 本地 JSON 中的计数器全部恢复，各计数桶与当前周期次数保持

#### Scenario: 名字与目标值校验
- **WHEN** 用户保存名字为空、超过 20 字或目标值为负数
- **THEN** 系统拒绝保存并提示，不写入持久化

### Requirement: 重置周期
系统 SHALL 支持天、月、年、永不清零四种重置周期；次数按"当前时间 + 周期"划分到计数桶，周期切换后当前次数从 0 重新累计，历史桶保留。

#### Scenario: 天周期按日清零
- **WHEN** 计数器周期为"天"且跨过午夜
- **THEN** 新一天显示 0 次，前一天次数保留在历史中

#### Scenario: 月周期按月清零
- **WHEN** 计数器周期为"月"且跨过月初
- **THEN** 新月份显示 0 次，上月次数保留在历史中

#### Scenario: 年周期按年清零
- **WHEN** 计数器周期为"年"且跨过年初
- **THEN** 新年度显示 0 次，上年度次数保留在历史中

#### Scenario: 永不清零持续累计
- **WHEN** 计数器周期为"永不清零"
- **THEN** 次数持续累计，不随日期切换重置

#### Scenario: 长期间隔后仍正确
- **WHEN** 应用关闭数天后重新打开
- **THEN** 当前周期次数按打开当天的桶计算，历史桶数据保持完整

### Requirement: 可选目标值
系统 SHALL 允许计数器设置目标值或留空；设置目标后按当前周期次数展示"还差 N 次"或"已达成"，未设置目标则只展示次数且不设上限。

#### Scenario: 未达成目标
- **WHEN** 计数器设置目标 8 且当前次数为 5
- **THEN** 卡片展示"还差 3"状态

#### Scenario: 达成目标
- **WHEN** 计数器当前次数达到或超过目标值
- **THEN** 卡片展示"已达成"状态

#### Scenario: 未设置目标
- **WHEN** 计数器未设置目标
- **THEN** 卡片只展示次数，继续 +1 不产生上限或提示

### Requirement: dashboard 卡片一键计数
系统 SHALL 为每个计数器在 dashboard 提供一张卡片，卡片上有一个独立的 + 按钮；点击一次当前周期次数 +1，不触发进入详情页、不影响卡片拖拽排序。

#### Scenario: 卡片加号计数
- **WHEN** 用户点击某计数器卡片上的 + 按钮
- **THEN** 该计数器当前周期次数 +1，卡片数字立即更新

#### Scenario: 加号不进入详情页
- **WHEN** 用户点击卡片上的 + 按钮
- **THEN** 不切换到该工具的详情页

#### Scenario: 卡片点击进入详情
- **WHEN** 用户点击卡片空白区域（非 + 按钮）
- **THEN** 进入该工具详情页

### Requirement: 详情页计数编辑
系统 SHALL 允许用户在详情页调整计数器的当前周期次数，支持 + 按钮、− 按钮与直接输入具体数值。

#### Scenario: 加号与减号
- **WHEN** 用户点击详情页某计数器条目的 + 或 − 按钮
- **THEN** 当前周期次数相应 +1 或 −1，减号下限为 0，数字即时更新

#### Scenario: 直接输入数值
- **WHEN** 用户点击次数数字并输入具体值
- **THEN** 当前周期次数更新为该值（下限 0）

#### Scenario: 详情页历史列表
- **WHEN** 用户在详情页查看计数器
- **THEN** 展示最近若干非零周期的历史次数（如最近 7 个周期），按时间倒序
