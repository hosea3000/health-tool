# 01 — 建立 Windows 监控闭环：待工作、工作段与闲置暂停

**What to build:** 用户启动 Windows 工具后，可从系统托盘看到待工作状态；首次有效活动开始工作段，持续键鼠操作维持工作段，连续 5 分钟无有效活动后进入闲置暂停。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 工具可由用户手动启动，并在系统托盘显示当前状态
- [ ] 启动后进入待工作，未发生有效活动时不创建工作段
- [ ] 键盘按键、鼠标点击、滚轮和明显鼠标移动可创建或维持工作段
- [ ] 微小鼠标抖动不会被识别为有效活动
- [ ] 连续 5 分钟无有效活动后进入闲置暂停，闲置时间不计入工作段
- [ ] 使用可注入时钟和活动事件覆盖状态边界，不依赖真实等待
