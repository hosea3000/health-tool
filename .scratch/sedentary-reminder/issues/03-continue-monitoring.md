# 03 — 支持托盘与通知继续

**What to build:** 用户可通过系统托盘或 Windows 通知中的继续操作恢复监控；继续后创建一个从 0 分钟开始的新工作段，重复操作不会造成重复状态转换。

**Blocked by:** 02 — 增加 60 分钟久坐提醒

**Status:** ready-for-agent

- [ ] 系统托盘提供继续操作
- [ ] Windows 通知提供继续操作
- [ ] 任一继续操作都从暂停进入待工作
- [ ] 继续后的首次有效活动创建新的工作段并从 0 分钟计时
- [ ] 继续不会继承上一工作段的已用时间
- [ ] 重复点击或过期操作不会创建重复工作段或重复提醒
- [ ] 覆盖托盘和通知两条恢复路径的行为测试
