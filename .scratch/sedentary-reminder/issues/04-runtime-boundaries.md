# 04 — 完成锁屏、睡眠与运行边界

**What to build:** 工具在 Windows 锁屏、睡眠和唤醒场景下不会误计工作段；用户数据保持最小化；程序可正常启动、显示托盘、发送通知并干净退出。

**Blocked by:** 03 — 支持托盘与通知继续

**Status:** ready-for-agent

- [ ] 锁屏和睡眠期间不推进工作段计时
- [ ] 解锁或唤醒后不会因输入自动恢复，仍需明确继续
- [ ] 只向领域逻辑提供活动类型和时间，不采集按键内容、鼠标坐标或窗口信息
- [ ] 不持久化活动历史、提醒历史或远程上传数据
- [ ] Windows 进程可启动并创建系统托盘控制
- [ ] 程序可干净退出并释放输入监听和通知资源
- [ ] 增加最小 Windows smoke check，验证启动、托盘、通知和退出闭环
