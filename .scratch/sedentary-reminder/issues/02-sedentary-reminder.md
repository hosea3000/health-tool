# 02 — 增加 60 分钟久坐提醒

**What to build:** 当工作段达到 60 分钟时，用户收到一次 Windows 通知，工具进入提醒暂停；暂停期间的输入不会自动恢复监控，也不会重复触发同一工作段的提醒。

**Blocked by:** 01 — 建立 Windows 监控闭环：待工作、工作段与闲置暂停

**Status:** ready-for-agent

- [ ] 工作段达到 60 分钟时发送一次 Windows 通知
- [ ] 发送通知后进入提醒暂停
- [ ] 提醒暂停期间的键盘和鼠标输入不会推进计时或恢复监控
- [ ] 同一个工作段最多发送一次久坐提醒
- [ ] 覆盖 60 分钟前、恰好 60 分钟和暂停后的输入边界测试
